# Changelog

All notable changes to the 99 Roots Studio website will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-12-08

### Added
- ✨ Full-screen hero section with studio logo and parallax effects
- ✨ Artists showcase section with individual artist cards
- ✨ Individual artist gallery pages with lightbox viewer
- ✨ Automated image slideshow gallery with 4-second intervals
- ✨ FAQ section with accordion-style questions and answers
- ✨ Location section with embedded Google Maps
- ✨ Shop section with "Coming Soon" page
- ✨ Contact footer with social media links
- ✨ Appointment booking integration (external)
- ✨ Mobile-optimized navigation with hamburger menu
- ✨ Cookie consent banner (GDPR compliant)
- ✨ Comprehensive parallax scrolling on all major sections
- ✨ Smart mobile navigation with one-time tutorial indicator
- ✨ Toast notifications for user feedback
- ✨ Smooth page transitions and fade effects
- ✨ Video background sections
- ✨ Responsive design for all screen sizes

### Design System
- 🎨 Soft black background (#151515) throughout
- 🎨 Gold accent color (#FF9D56) for typography and highlights
- 🎨 Roboto font for headings
- 🎨 Space Mono font for body text
- 🎨 Minimalistic, premium aesthetic with ample white space
- 🎨 Signature diamond decorative elements

### Navigation
- 🧭 Fixed navigation bar that appears on scroll
- 🧭 Smooth scroll to sections
- 🧭 Mobile slide-in drawer menu
- 🧭 Logo serves as home button on desktop
- 🧭 Logo opens menu on mobile with pulsing tutorial indicator
- 🧭 One-time navigation tutorial for first-time mobile users

### Mobile Features
- 📱 Fully responsive layouts
- 📱 Touch-optimized interactions
- 📱 2-column gallery grids on mobile
- 📱 Full-screen lightbox images
- 📱 Optimized padding and spacing
- 📱 Touch-friendly button sizes (44x44px minimum)
- 📱 Smart navigation indicator after cookie acceptance

### Performance
- ⚡ Lazy loading for images and videos
- ⚡ Optimized parallax with CSS transforms
- ⚡ Code splitting for page components
- ⚡ Minimal bundle size with tree-shaking
- ⚡ Responsive image breakpoints

### Technical
- 🔧 Built with React 18.x and TypeScript
- 🔧 Styled with Tailwind CSS 4.0
- 🔧 Animations with Motion (Framer Motion)
- 🔧 UI components from shadcn/ui
- 🔧 Icons from Lucide React
- 🔧 Toast notifications with Sonner
- 🔧 Build tool: Vite

### Documentation
- 📚 Comprehensive README with setup instructions
- 📚 Design guidelines (Guidelines.md)
- 📚 Component documentation
- 📚 Contributing guidelines (CONTRIBUTING.md)
- 📚 Asset attributions (Attributions.md)
- 📚 Changelog (this file)

### Accessibility
- ♿ High contrast color scheme
- ♿ ARIA labels for interactive elements
- ♿ Keyboard navigation support
- ♿ Alternative text for images
- ♿ Touch-friendly mobile interface

## Version History

### Version Naming Convention
- **Major (x.0.0):** Breaking changes or major redesigns
- **Minor (1.x.0):** New features or significant updates
- **Patch (1.0.x):** Bug fixes and minor improvements

### Release Notes Format
- ✨ Added: New features
- 🔧 Changed: Changes to existing functionality
- 🐛 Fixed: Bug fixes
- 🗑️ Removed: Removed features
- 🔒 Security: Security improvements
- ⚡ Performance: Performance improvements
- 🎨 Design: Design updates
- 📚 Documentation: Documentation changes
